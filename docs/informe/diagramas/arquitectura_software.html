Diagrama de arquitectura de software – RecuperaYa

Aplicación web monolítica cliente-servidor en 3 capas con patrón MVC (Laravel 12)
Usuarios (cliente)
Estudiante / docente / personalBusca en el catálogo, reporta pérdidas y reclama objetos.
Encargado de custodiaRegistra objetos, verifica y registra entregas, consulta reportes.
AdministradorUsuarios, roles, categorías, lugares y datos para ML.
Navegador webChrome / Edge / celular (diseño responsivo, sin instalación).
▼ HTTP: peticiones GET/POST/PUT/DELETE · formularios con token CSRF · cookie de sesión   ▲ HTML renderizado
Capa de presentación (vistas)
Plantillas Bladelayouts/app, layouts/acceso, partials (mensajes, errores, tarjeta de objeto)
Vistas por móduloauth, catalogo, objetos, reportes, reclamos, entregas, estadisticas, notificaciones, admin
Recursos estáticospublic/css/app.css, JavaScript, íconos SVG, Google Fonts (Poppins)
▼ datos para la vista ($objetos, $r, $errors)   ▲ entrada del usuario
Capa de aplicación / lógica de negocio (Laravel 12 – MVC)
Rutas (routes/web.php)Route::resource con verbos en español (/objetos/crear, /editar) y URLs amigables por slug
Middleware y Gatesguest, auth, can:reportar · can:gestionar · can:administrar (control por rol), CSRF, bloqueo tras 5 intentos fallidos
Form Requests (validación)RegistroRequest, LoginRequest, StoreObjetoRequest, UpdateObjetoRequest, StoreReclamoRequest…
ControladoresAuth, Catalogo, Objeto, ReportePerdida, Reclamo, Entrega, Estadistica, Notificacion, Admin\Usuario / Categoria / Lugar
ServiciosMotorCoincidencias (puntaje 0-100) · ReclamoService (verificación) · EstadisticaService (indicadores, CSV, dataset ML) · Notificador · ImagenService · Texto
Modelos Eloquent (ORM)User, Objeto, Categoria, Lugar, ReportePerdida, Coincidencia, Reclamo, Entrega, Notificacion, Auditoria
Módulos funcionales
M1 Acceso y usuariosRegistro con correo institucional, login, roles
M2 Registro y custodiaCRUD de objetos con foto y preguntas
M3 Búsqueda y pérdidasCatálogo con filtros y reportes de pérdida
M4 Coincidencias y avisosCruce automático y notificaciones
M5 Reclamo y entregaPreguntas de verificación, carné, entrega
M6 Reportes y análisisIndicadores, filtros, PDF, CSV, ML
▼ consultas SQL generadas por Eloquent / Query Builder (PDO)   ▲ registros
Capa de datos
Base de datos MySQL / MariaDB – recuperaya_laravelusers · categorias · lugares · objetos · reportes_perdida · coincidencias · reclamos · entregas · notificaciones · auditorias · sessions · cache · jobs (creadas con migraciones de Laravel)
Almacenamiento de archivosstorage/app/public: fotos de los objetos (JPG/PNG, máx. 5 MB)
Servicios externos
Servidor de correo (SMTP)Funcionalidad: enviar avisos de coincidencias y reclamos.
Datos: destinatario, asunto, mensaje y enlace.
Integración: Laravel Mail (MAIL_MAILER); en desarrollo usa el driver log.
Google Fonts (CDN)Funcionalidad: tipografía Poppins de la interfaz.
Datos: hoja de estilos (solo lectura).
Google ColabFuncionalidad: modelo de machine learning (pandas, scikit-learn).
Datos: dataset CSV anónimo exportado por el administrador (variable recuperado_30d).
Sin APIs de pago ni de geolocalizaciónEl servicio es interno y gratuito; los lugares del campus son una lista configurable.
Elaboración propia a partir del código fuente del proyecto.
